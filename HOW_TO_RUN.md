# Mass Near Me — how to run & install

A Progressive Web App: an interactive map of every Roman Catholic parish in Winnipeg
and St. Boniface, with the next Mass / confession / adoration near you.

## Files
- `index.html` — the app
- `parish_data.js` — the data (56 parishes, 224 Mass times) — auto-regenerated by the weekly refresh
- `manifest.webmanifest`, `sw.js`, `icons/` — make it installable & work offline

## Try it now (quickest)
Double-click `index.html` to open it in your browser. The map, search and parish details
all work this way. (The only things that need a hosted version are home-screen install and
offline caching — see below.)

## Run it as a real installable app (recommended)
A PWA must be served over http(s), not opened as a file, to install to your phone.

Easiest local option — in Terminal:
```
cd "/Users/shadmoreno/Documents/PersonalWorks/Mass and Visits/app"
python3 -m http.server 8000
```
Then open http://localhost:8000 in your browser. To install on a phone on the same Wi-Fi,
open http://<your-computer-ip>:8000 on the phone → Share → "Add to Home Screen".

## Keeping the phone app's times current
The app caches itself for offline use. Since 2026-08-31 it fetches `parish_data.js`
network-first, so an installed app picks up new times automatically the next time it is
opened with an internet connection. Two things still matter:
1. **The host must have the new files.** If you put the app on Netlify/GitHub Pages/etc.,
   re-upload the `app/` folder after each weekly refresh; the refresh only updates this
   folder on your computer. (If you serve it from your Mac with `http.server`, nothing to do.)
2. The header shows "Times updated YYYY-MM-DD" so you can always check what data the
   phone is using. If it is stale, open the app twice while online (first open installs
   the updated service worker, second open loads fresh data).

## Put it on your phone for good
To have it on your phone anywhere (not just same Wi-Fi), host the `app/` folder on any
static host — e.g. Netlify Drop (drag the folder in), GitHub Pages, or Cloudflare Pages.
You'll get an https link; open it on the phone and "Add to Home Screen". That's the same
icon-on-the-homescreen experience as a native app.

## How to use
- **Just ask, in plain English.** Type into the top bar, e.g.
  *"I'll be on 201 Portage Avenue tomorrow at 10 AM — what are the closest Masses around it?"*
  It works out the place, day, time and whether you mean Mass / confession / adoration,
  finds the location on the map, and lists the closest options. More examples:
  *"confession near 845 Dakota St Saturday afternoon"*, *"adoration near me in the next hour"*,
  *"Mass downtown Friday 5–7 pm"*. (Naming a location needs an internet connection to look it up.)
- Or use the manual controls below the bar:
- Tap **"Next hour, near me"** for the closest Mass starting within 60 minutes (uses GPS).
- Or set **Day + From/To time**, pick a location (📍 My location, or tap the map), and **Search**.
- Switch between **Mass / Confession / Adoration** at the top.
- Tap any pin or result for full times, phone, website and directions.
- Pin colour: deep red = Archdiocese of Winnipeg, blue = Archdiocese of Saint Boniface.

Times are sourced from each parish's current bulletin where possible; tap a parish to see the
source and confidence. The data refreshes automatically every Monday.
